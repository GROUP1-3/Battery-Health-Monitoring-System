## Project Description
This project is a C++ application that monitors the health of a 12 V battery. It records voltage readings, classifies the battery condition, calculates the average, minimum, and maximum voltages, and saves the report to a text file.

## Features
- Enter Battery ID
- Record multiple voltage readings
- Validate user input
- Classify battery status
- Calculate average, minimum, and maximum voltage
- Save report to `battery_report.txt`

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- GitHub

## How to Run
1. Open the project in Code::Blocks or Visual Studio Code.
2. Compile the `main.cpp` file.
3. Run the program.
4. Enter the required battery information.
5. View the report on the screen and in `battery_report.txt`.

## Expected Output
The program displays:
- Battery ID
- Average Voltage
- Minimum Voltage
- Maximum Voltage
- Battery Status
- Overall Recommendation
